# Lumina Creative Studio

A modern, responsive website for **Lumina Creative Studio** – a creative agency specializing in photography, web design, and graphic design.

## 🎨 Overview

Lumina Creative Studio is a professional creative agency based in Nairobi, Kenya. This website showcases the studio's portfolio, services, and team members. The site features an elegant design with smooth navigation and a beautiful portfolio gallery.

**Location:** Fortis Suites, 5th Ngong Avenue, Nairobi, Kenya

## ✨ Features

- **Responsive Design** – Fully responsive and mobile-friendly layout
- **Portfolio Gallery** – Interactive image gallery with lightbox functionality
- **Services Showcase** – Detailed descriptions of photography, web design, and graphic design services
- **Team Section** – Meet the talented team members behind Lumina
- **Modern UI** – Clean, professional design with smooth animations
- **Contact Information** – Easy access to contact details and social media links
- **Multi-page Navigation** – Home, About, and Contact pages

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/FelixPatric/lumina.git
   ```

2. Navigate to the project directory:
   ```bash
   cd lumina
   ```

3. Open `index.html` in a web browser to view the site locally

4. Deploy to GitHub Pages or any hosting service

## 💡 Customization

- **Colors & Styling:** Modify `css/styles.css` to change the design
- **Images:** Replace portfolio and team images in the `images/` folder
- **Content:** Edit HTML files to update text, services, or team information
- **Links:** Update navigation and footer links as needed
